 Student Record Management System 🎓

A lightweight, robust command-line interface (CLI) application built with Python and SQLite for managing university student academic records. 

🛠️ Features
- Database Persistence: Uses relational SQLite database storage for record persistence.
- Full CRUD Support: Allows creation, reading, searching, and deletion of student records.
- Data Integrity & Validation: Enforces strict constraints on unique Primary Keys (Matric Numbers) and CGPA limits (0.00 - 5.00).
